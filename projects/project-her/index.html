Project HER: Autonomous Article to Video AI Agent

A personal article-to-video project deployed on Google Cloud Run, combining script generation, narration, media selection, and rendering.

1. Overview

Project HER explores how a staged workflow can turn a topic or article into a narrated short video. It connects script generation, speech, visual assets, and programmatic composition.

I packaged the project in a Docker container and deployed the demo on Google Cloud Run. Its availability can vary with the external service.

2. The Problem

Making a short educational video involves several manual steps:

  • Scripting and timing hook sentences.
  • Recording and cleaning up voiceover audio tracks.
  • Sourcing relevant, high-resolution B-roll footage.
  • Aligning karaoke-style captions and exporting heavy video timelines.

3. The Solution

Project HER implements an automated 5-stage pipeline executed asynchronously:

1. Content Extraction ──► Scrapes article or accepts story prompt │ 2. Scene Breakdown ──► Gemini 2.5 Flash partitions into 5-8 second scenes │ 3. Neural Narration ──► Generates TTS audio & computes word-level subtitle timings │ 4. Media Retrieval ──► Queries visual APIs (Pexels) for matched high-res clips │ 5. Composition Engine ──► Remotion composes captions, visuals & MP4

4. Technical Architecture & Decisions

  • Model Selection (Gemini 2.5 Flash): Used to produce scene breakdowns that the renderer can consume.
  • Asynchronous Job Queue: Video rendering is CPU-intensive. The FastAPI backend returns a job ID immediately and streams progress via Server-Sent Events (SSE) and polling endpoints.
  • Dynamic Subtitle Alignment: Uses neural voice timestamp markers to generate word-by-word highlighted captions synchronized to speech cadence.
  • GCP Cloud Run Deployment: Containerized with FFmpeg and Python dependencies, scaling dynamically based on generation requests.

5. Engineering Challenges Overcome

Cold Starts & Rendering Timeouts: Video composition is sensitive to cold starts, input length, and container memory. The demo uses an asynchronous job flow so visitors can see progress while rendering continues.

API Resilience: Sourced media clips are validated for dimensions and bitrate before rendering; if an asset is unavailable, the pipeline smoothly falls back to thematic abstract motion backgrounds.

6. Live Interactive Demo

The public demo runs on an external service. Open it to try a topic or article URL; generation may be unavailable during cold starts or service outages.

Evaluation & limits

There is no published benchmark here for render time, output quality, or cost. Results depend on the source article, available media, and external APIs. The 14-second video asset in this repository is a promotional overview, not a recording of a generated result.
